# ギリシャ語OCR（GreekOCR-redo）

[English](README.md)

これまで私は、ギリシャ語を含む欧文の書籍や論文を、購入後に FineReader や Acrobat Pro で読み取り、電子書類として利用してきました。しかし、下に述べるように、古典ギリシャ語の部分は正しく認識されません。JSTOR などからダウンロードできる論文にも、同じ問題があります。しかも、それらの多くにはメモや付箋を付けているため、古典ギリシャ語に対応した最近のOCRアプリで読み直そうとすると、メモや付箋が扱えないという悩みがありました。

このツールは、付箋やメモを残したまま、古典ギリシャ語（アクセントや気息記号の付いた多調式ギリシャ語）を含むPDFを **Tesseract** と **OCRmyPDF** で読み直し、ギリシャ語を正しくコピー・検索できるようにする Mac 用のツールです。すでに使っているPDFをまとめて直すためのものなので、フォルダ単位で処理します。フォルダをアプリにドロップすると、中のPDFを1冊ずつ処理します。新しく入手したPDFを読み取る場合は、[EuroOCR](https://github.com/MasahiroKitano/EuroOCR) をご利用ください。

## どんな問題を解決するか

Adobe Acrobat や ABBYY FineReader でOCRしたPDFは、英語・ドイツ語・フランス語などの本文は読めても、古典ギリシャ語の部分が文字化けします。

- Acrobat は古典ギリシャ語に対応していないため、ギリシャ語をコピーすると `'t.�Jov` のような記号の並びになります。
- FineReader はギリシャ語を現代ギリシャ語として読むため、気息記号や曲アクセントなどが落ちます。

このツールで処理すると、同じ箇所が `ζῷον`、`καλόν`、`τεταγμένα` のように取れるようになります。

## 特長

- **付箋・ノート・ハイライトを残す**：ページを作り直す場合も、元のPDFから注釈を移し直します。
- **ファイルの種類を自動で見分ける**：Acrobatの「検索可能な画像」、ClearScan、FineReaderでOCR済みのもの、文字層のないスキャン、最初から文字のある電子版、日本語の本を判定し、それぞれに合った処理を選びます。
- **本文の言語を自動で判定する**：英語・ドイツ語・フランス語・イタリア語・スペイン語・ラテン語を見分けて、「本文の言語＋古典ギリシャ語」で認識します。2つの言語が混じる本（ラテン語の引用が多いドイツ語の本など）は、両方を指定します。
- **元のファイルは書き換えない**：結果は別のフォルダに、サブフォルダの構造ごと保存します。
- **途中で止めても続きから再開できる**：処理済みのファイルは自動で飛ばします。
- **best版の認識データに対応**：時間はかかりますが、精度を優先できます。

## 必要なもの

- macOS（Apple Silicon・Intel）
- [Homebrew](https://brew.sh)
- ディスクの空き：ソフトと認識データで数GB。処理結果は元のPDFと同程度から数倍（下の「注意点」）

作者は MacBook Air（M1）で、1000冊以上のPDFに使って動作を確かめています。Windows と Linux では検証していません。

## インストール

1. このページの「Code」→「Download ZIP」でダウンロードし、展開します。
2. 「ターミナル」を開き、`cd ` と入力して（後ろに空白を1つ）、展開したフォルダをターミナルの窓にドラッグし、Returnキーを押します。
3. 次の1行を実行します。

```
bash install.sh
```

`install.sh` は次の作業を自動で行います。

1. Homebrew で Tesseract、言語データ、OCRmyPDF、pngquant をインストールする
2. `greek_ocr.py` を `~/GreekOCR` に置く
3. best版の認識データ（grc eng deu fra ita spa lat）を `~/GreekOCR/tessdata_best` にダウンロードする
4. 「ギリシャ語OCR」アプリを「アプリケーション」フォルダに作る

アプリはお使いのMacの上で作られるので、「開発元を確認できません」という警告は出ません。best版データが要らなければ `bash install.sh --no-best` を使ってください。

## 使い方

1. PDFの入ったフォルダを「ギリシャ語OCR」アプリにドロップします（アプリをダブルクリックしてフォルダを選ぶこともできます）。
2. 認識データを選びます。**best版**は精度優先、**通常版**は速度優先です。
3. 処理内容を選びます。
   - **下見のみ**：各PDFの判定を表示するだけで、何も書き換えません。最初に一度使うと安心です。
   - **OCR開始**：処理します。
   - **強制OCR**：種類に関係なく、すべてのページを作り直して認識します。自動判定で直らなかった本に使います。
4. ターミナルに進み具合が表示され、終わると通知が出ます。途中で止めるときは、その窓で `control + C` を押します。

結果は、ドロップしたフォルダの隣の「フォルダ名_OCR済み」に保存されます。そこに `OCR処理ログ.txt` もでき、1冊ごとの判定、言語、ファイルサイズの変化、処理時間が記録されます。

ターミナルから直接使うこともできます。

```
~/GreekOCR/greek-ocr.sh フォルダ [--dry-run] [--force] [--fast] [--out 保存先] [--jobs 4]
```

## ファイルの種類ごとの処理

| 判定 | 見分け方 | 処理 |
| --- | --- | --- |
| 日本語中心 | 文字層、または試し読みで、かな・漢字が中心 | そのままコピー |
| 検索可能な画像 | 透明な文字層が中心 | 透明な文字層だけを入れ替える。速く、サイズもほぼ変わらない |
| ClearScan | 見える文字と白黒の画像の断片がある、または作成ソフトが Acrobat の Paper Capture | ページを作り直して認識し、注釈を移し直す |
| FineReaderでOCR済み | 作成ソフトが FineReader で、ギリシャ文字を含む | ClearScan と同じ |
| 現代ギリシャ語として認識済み | ギリシャ文字は多いのに、気息記号などの付いた文字がほとんどない | ClearScan と同じ |
| 文字層なし | 文字がない | 通常のOCR |
| 電子版 | 上のどれでもない、最初から文字のあるPDF | そのままコピー |

## 注意点

- **認識は完璧ではありません。** 誤認識は残りますが、ページの見た目は元のままです。コピーや検索のための文字層を改善するものと考えてください。
- **ファイルサイズ**：ページを作り直す本（ClearScanなど）は大きくなります。作者の環境では元の1.1〜1.4倍程度が多く、3倍近くになった本もありました。「検索可能な画像」はほとんど変わりません。
- **処理時間**：通常版で1ページあたり1〜4秒程度です。best版はそれより遅くなります。
- Acrobat はギリシャ語をギリシャ文字として記録しないので、ClearScan の本はギリシャ語の有無にかかわらず作り直します。
- FineReader でギリシャ語を認識言語に入れずにOCRした本は、自動では見分けられません。「強制OCR」で処理してください。
- 処理済みのPDFをもう一度処理しないでください。作り直しが重なって画質が落ちます。必ず元のファイルを処理してください。
- 長時間の処理中は、電源につなぎ、MacBook のふたは開けたままにしてください（本体のスリープは自動で防ぎます）。
- 元のPDFのバックアップを取ってから使うことをおすすめします。

## 著作権について

このツールは、ご自身が持っているPDFを私的に利用しやすくするためのものです。処理したPDFを公開・共有する場合は、元の書籍や論文の著作権に従ってください。
